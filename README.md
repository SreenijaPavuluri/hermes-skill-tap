# Hermes skill tap

Hermes Agent skills by Sreenija Pavuluri.

| Skill | What it does |
|---|---|
| `deadline-radar` | Ranks deadlines from a plain Markdown file by urgency and effort. No accounts, network or API keys. |

## Install

```bash
hermes skills tap add SreenijaPavuluri/hermes-skill-tap
hermes skills install SreenijaPavuluri/hermes-skill-tap/deadline-radar
```
